# Contributing to ArchCalc

Thanks for considering a contribution! Bug reports, features, docs, translations of ideas into new Quote Studio builders — all of it helps.

## Ways to contribute

- **Report a bug** with the [Bug Report](https://github.com/murtazapatel89100/ArchCalc/issues/new?template=bug_report.md) template. Include your OS, ArchCalc version, how you installed it and steps to reproduce.
- **Suggest a feature** with the [Feature Request](https://github.com/murtazapatel89100/ArchCalc/issues/new?template=feature_request.md) template. Explain *why* it would help other people too.
- **Send a pull request** for a fix or feature — for anything large, open an issue first so we can agree on the approach.
- **Add a Quote Studio builder** for a trade you know (see [Adding a builder](app/ARCHITECTURE.md#adding-a-quote-studio-builder)).
- **Improve the docs** in [`web/content/docs`](web/content/docs).

## Development setup

You need [Node.js](https://nodejs.org/) 20+, [pnpm](https://pnpm.io/) 11, the [Rust toolchain](https://rustup.rs/) and the [Tauri prerequisites](https://tauri.app/start/prerequisites/) for your OS.

```bash
git clone https://github.com/<you>/ArchCalc.git
cd ArchCalc

cd app && pnpm install && pnpm tauri dev   # desktop app
cd web && pnpm install && pnpm dev         # website & docs (http://localhost:3000)
```

The repository is a monorepo: [`app/`](app) is the Tauri + SolidJS desktop app and [`web/`](web) is the Next.js + Fumadocs website. Start with [`app/ARCHITECTURE.md`](app/ARCHITECTURE.md) to find your way around the app.

## Making a change

1. **Branch** from `main` (`feat/…`, `fix/…`, `docs/…`).
2. **Code** following the existing style. The app uses SolidJS primitives (`createSignal`, `createMemo`, `createEffect`) — not React hooks — and all system access goes through Tauri commands.
3. **Test** what you changed:
   - Pure logic (pricing, exports, parsing) gets [Vitest](https://vitest.dev/) tests next to the code (`*.test.ts`). Run `pnpm test` in `app/`.
   - Rust code gets `#[cfg(test)]` unit tests. Run `cargo test` in `app/src-tauri/`.
4. **Check** — these are exactly what CI runs, and all must pass:

   ```bash
   # in app/ and web/
   pnpm dlx @biomejs/biome check ./        # add --write to auto-fix formatting

   # in app/src-tauri/
   cargo fmt -- --check
   cargo clippy --workspace --all-targets --all-features -- -D warnings
   ```

5. **Docs** — if users will notice the change, update the relevant page in [`web/content/docs`](web/content/docs). Screenshots and videos in `web/public` are generated by `pnpm showcase` in `app/` (needs `ffmpeg` and a Playwright Chromium: `pnpm exec playwright install chromium`).
6. **Commit** using [Conventional Commits](https://www.conventionalcommits.org/), e.g. `feat(app): add a cake builder`, `fix(app): round percentage results`, `docs(web): explain spreadsheet export`. Versions and the [changelog](CHANGELOG.md) are generated from these by release-please, so the prefix matters.
7. **Open a pull request** against `main` and fill in the template. CI must be green before merging.
