## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in ArchCalc, please report it via private email or the GitHub Security Advisory private reporting feature.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a vulnerability is confirmed, we will release a patch as quickly as possible.
