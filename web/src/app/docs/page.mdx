# Welcome to ArchCalc Documentation

ArchCalc is the definitive workspace and developer tools platform. It integrates a powerful interactive Live Notebook, advanced system reading capabilities, and essential developer utilities into a single, cohesive interface.

## Features at a Glance

1. **Interactive Workspace**: A Live Notebook calculator that parses variables and arithmetic in real-time.
2. **System Dashboard**: Real-time insights into your hardware usage (CPU, RAM, Network) and OS details.
3. **Everyday Utilities**: Built-in developer tools like hashing (SHA-256, MD5), UUID generation, base64 encoding/decoding, and more.
