# Developer Tools

A suite of built-in developer tools is available directly within ArchCalc, eliminating the need to search for online utilities.

## Available Utilities

- **Hash Generator**: Generate MD5, SHA-1, SHA-256, and SHA-512 hashes.
- **UUID Generator**: Generate v4 UUIDs instantly.
- **Timestamp Converter**: Convert Unix epoch to human readable dates.
- **Base64 Encoder**: Encode and decode strings.
- **JSON Formatter**: Prettify and validate JSON structures.
- **Binary Converter**: Convert text to binary and vice-versa.
- **Hex Converter**: Convert text to hexadecimal.
- **Storage Converter**: Convert between Bytes, KB, MB, GB, and TB.

You can access these tools by navigating to the Developer Tools section via the sidebar.
