# Developer Tools

A suite of built-in developer tools is available directly within ArchCalc, eliminating the need to search for online utilities.

## Available Utilities

- **Hash Generator**: Generate SHA-1, SHA-256, SHA-512, MD5, and more.
- **Base64 Encoder/Decoder**: Quickly convert strings and files.
- **JSON Formatter**: Format and validate JSON structures.
- **Regex Tester**: Test regular expressions against input strings in real-time.

You can access these tools by clicking the `Tools` icon in the navigation bar or using the command palette.
