# Workspace

The ArchCalc Workspace is your central hub for development. It provides an isolated, highly configurable environment tailored for maximum productivity.

## Managing Projects

You can link local directories to ArchCalc to track them as projects. The workspace will automatically index the files and provide quick search capabilities.

## Terminal Integration

The integrated terminal supports standard shell environments (bash, zsh, powershell). You can split terminal panes, run background tasks, and manage processes directly from the UI.
