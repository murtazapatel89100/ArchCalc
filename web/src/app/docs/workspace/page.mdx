# Workspace (Live Notebook)

The ArchCalc Workspace serves as an interactive scratchpad and live calculator. It allows you to rapidly perform calculations, assign variables, and see the results evaluated in real-time right alongside your notes.

## Live Calculation

The workspace evaluates mathematical expressions line by line. You can assign values to variables and reuse them in subsequent lines.

```text
salary = 50000
rent = 12000
food = 5000

// Calculate remaining
remaining = salary - rent - food
```
As you type, the live results panel instantly displays the evaluated output for each line, handling large numbers and floating point arithmetic cleanly.

## Managing Workspaces

You can create multiple distinct workspace pages to organize different calculations or notes. 
- Create new workspaces using the sidebar.
- Switch between them instantly.
- Workspaces are automatically saved locally, ensuring you never lose your progress.
