# System Dashboard

ArchCalc's System Dashboard provides a clean, unified view to monitor host hardware resources in real-time.

## Capabilities

- **CPU Metrics**: Track total CPU usage percentage over time and view total logical cores.
- **Memory Tracking**: View RAM and Swap utilization (used vs total) with real-time graphs.
- **Network**: Track global active download and upload speeds (Rx/Tx) across all network interfaces.
- **System Information**: View operating system name, kernel version, and system uptime.

*Note: Some metrics may require elevated permissions depending on the host OS.*
