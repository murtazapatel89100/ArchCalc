# System Reading

ArchCalc's System Reading module allows you to monitor host hardware and software configurations in real-time.

## Capabilities

- **CPU Metrics**: Track usage per core, temperature, and clock speeds.
- **Memory Tracking**: View RAM and Swap utilization.
- **Disk I/O**: Monitor read/write speeds and free space across partitions.
- **Network**: Track active connections, bandwidth usage, and latency.

*Note: Some metrics may require elevated permissions depending on the host OS.*
