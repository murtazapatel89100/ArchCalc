## Command bar

The dashboard's command bar takes anything: maths (`(85000 - 22000) * 12`), unit conversions (`5 km to mi`), percentages (`18% of 4999`) and developer commands such as `uuid`, `sha256 <text>`, `base64 encode <text>` and `now`. Press **Enter** to save the result to your history. **Ctrl + Space** jumps back here from anywhere.

<Video src="/videos/clip-dashboard.mp4" title="Command bar" />

## Scientific calculator

A full keypad with trigonometry, inverse trig, logarithms, roots, powers, factorial, π and e, plus a **DEG / RAD** toggle. Every expression is parsed and evaluated by ArchCalc's Rust AST engine. See [Getting Started](/docs/getting-started#using-the-scientific-calculator) for the full function list.

<Video src="/videos/clip-calculator.mp4" title="Scientific calculator" />

## History

Every result from the command bar is kept locally and is searchable. Choose how long to keep it under **Settings → General**.

<Video src="/videos/clip-history.mp4" title="History" />

## Workspaces

Notepad-style sheets where each line is calculated live. Assign variables (`rent = 22000`), reuse them on later lines, and add `//` comments. Great for budgets and quick estimates.

<Video src="/videos/clip-workspaces.mp4" title="Workspaces" />

## Converters

Length, weight, temperature and storage conversions with instant results.

<Video src="/videos/clip-converters.mp4" title="Unit converters" />

## Developer tools

Hash generator (SHA-1, SHA-256, SHA-512), UUID generator, timestamp converter, Base64, JSON formatter, binary, hex and storage converters.

<Video src="/videos/clip-devtools.mp4" title="Developer tools" />

## System monitor

Live CPU, memory, swap and network usage, plus OS, kernel and uptime.

<Video src="/videos/clip-system.mp4" title="System monitor" />

## Quote Studio

Cost builders for 3D printing, freelancing, baking, tailoring, crafts, catering, printing and painting. Save several quotes per product, compare them, and export branded PDF, Word or Markdown quotes. Read the full guide in [Quote Studio](/docs/quote-studio).

<Video src="/videos/clip-quote-studio.mp4" title="Quote Studio" />

## Settings

Personalise the workspace badge, set history retention, view keyboard shortcuts, and export, import or clear all of your data, including saved quotes.
