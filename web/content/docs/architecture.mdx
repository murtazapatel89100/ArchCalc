title: Architecture
description: How ArchCalc splits work between a Rust backend and a reactive SolidJS frontend.
---

ArchCalc is a [Tauri 2](https://tauri.app/) desktop app. The interface is built with SolidJS and Tailwind CSS; anything that needs to be native or fast runs in Rust and is called through Tauri's IPC bridge.

```text
SolidJS UI  ──invoke()──▶  Rust command  ──▶  calculator engine · storage · system APIs
     ▲                                                     │
     └──────────────────────── result ◀────────────────────┘
```

## Rust backend

- **Math engine** — a custom tokenizer, parser and AST evaluator for every expression typed in the calculator, command bar and workspaces.
- **System monitor** — CPU, memory, swap, network and OS details via `sysinfo`.
- **File writing** — saves exported quotes to the location you pick in the native save dialog, and only as `.pdf`, `.docx`, `.md`, `.xlsx` or `.csv`.

## SolidJS frontend

- **Fine-grained reactivity** — results, breakdowns and previews update as you type without re-rendering whole screens.
- **Quote Studio** — pricing, Markdown rendering, and PDF, Word and Excel generation all run locally in the app.
- **Local data** — history, workspaces and quotes are stored on your machine. **Settings → Data** exports, imports or clears all of it.

## Privacy

ArchCalc works offline. It has no account, no telemetry and doesn't send your calculations or quotes anywhere.
