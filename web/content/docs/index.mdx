ArchCalc is a fast, lightweight, and extensible desktop calculator. It combines a powerful Rust-based mathematical engine with a sleek and responsive SolidJS user interface, distributed via Tauri.

## Features at a Glance

1. **Command bar**: Maths, unit conversions, percentages and developer commands (`uuid`, `sha256 …`, `base64 …`, `now`) in one box on the Dashboard.
2. **Scientific calculator**: Trigonometry and inverses, logarithms, roots, powers, factorial and the constants π and e, with a **DEG / RAD** toggle — evaluated by a custom Rust engine.
3. **History**: Every result is saved locally and searchable, with configurable retention.
4. **Workspaces**: Notepad-style sheets where each line is calculated live, with variables — great for budgets.
5. **Converters**: Length, weight, temperature and storage.
6. **Developer tools**: Hash generator, UUID generator, timestamp converter, Base64, JSON formatter, binary and hex converters.
7. **System monitor**: Live CPU, memory, swap and network usage.
8. **Quote Studio**: Cost builders for 3D printing (with multiple filament spools), freelancing, baking, tailoring, crafts, catering, printing and painting. Organise products and their quotes, add Markdown notes and terms, and export PDF, Word, Markdown or a live Excel spreadsheet. See [Quote Studio](/docs/quote-studio).
9. **Private and offline**: No account and no telemetry — your data stays on your machine, and Settings can export, import or clear all of it.
10. **Cross-platform**: Linux (AUR, `.deb`, `.rpm`) and Windows (`.msi`, `.exe`), with a small footprint thanks to Tauri.
